Lumos

A private, self-hosted household assistant — one household, two people. It is not a public service: nobody else can sign up for it or use it.

What Lumos is

Lumos is a self-hosted software deployment running on a private server in the operator's home. It is operated for, and used by, a single household — the operator and their partner. It is not distributed, not offered as a service, and has no other users.

Lumos connects to its own Google account — a dedicated account created for the deployment — using Google's standard OAuth 2.0 authorisation flow. When a household member asks it to do something (record a baby-care log entry, sync the household's shared checklist, tidy household mail, add an appointment), Lumos calls the relevant Google API with that account's own authorised credentials. Every action is triggered by a household member.

Why each permission is requested

  • auth/spreadsheets — read and update the household's shared baby-care checklist in Google Sheets, for the household's own two members. In active use.

Lumos requests the narrowest scope that covers its function. Any further scope is added only when a household feature actually needs it, is limited to the purpose stated beside it, and is never used to serve anyone outside the household.

Data handling

OAuth tokens, and any data Lumos stores, remain on the household's own server; tokens are protected by operating-system file permissions and are never transmitted to a third party for storage. Nothing is sold, and nothing is disclosed to third parties for advertising or any other purpose. Full detail — including retention and how to revoke access — is in the privacy policy.
