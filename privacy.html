Privacy policy — Lumos

Last updated: 28 September 2026

Overview

Lumos is a personal, non-commercial software project, built and operated by one individual for their own household. It is not a public product, it has no other users, and no third party can create an account or obtain access to it. This policy explains what data Lumos accesses through Google APIs, and what happens to it.

What Lumos does with Google data

Lumos connects to its own dedicated Google account using Google's official OAuth 2.0 authorisation flow. At the direction of a household member it can read and update a shared checklist in Google Sheets, read and add calendar events, read, send and organise mail in that account, look up the account's own contacts, and read Google Docs shared with it. Data accessed through Google APIs is used solely to carry out those requests for the household.

Google user data and Limited Use

Lumos's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide the user-facing features described on the home page; it is never transferred to others except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition — and never for advertising or for training generalised AI/ML models.

Data storage

OAuth tokens and any records Lumos keeps (for example, checklist state or log entries the household asked it to record) are stored on the operator's own private server, protected by operating-system user-account file permissions. Tokens are never transmitted to, or stored on, any third-party server. The pages you are reading are static files hosted by GitHub Pages and set no cookies and run no analytics.

Data sharing

No Google user data is sold, rented, or shared with third parties. It is not used for advertising, profiling, or determining creditworthiness. Where a household member asks Lumos to summarise or otherwise process content, that specific content may be sent to the AI model provider configured for that task, solely to produce the requested result; it is not retained by Lumos elsewhere, and no Google user data is used to train models.

Retention and deletion

Records Lumos stores are kept only as long as the household needs them, and can be deleted on request. OAuth tokens are retained until access is revoked.

Revoking access

Access can be revoked at any time from the Google account's permissions page at myaccount.google.com/permissions, which immediately invalidates Lumos's stored token. To ask for deletion of any data Lumos has stored, use the contact address below.
